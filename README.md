# Sumesh J — Personal Portfolio & Digital Garden

A minimalist, high-performance personal portfolio and digital garden for **Sumesh J** (Applied AI & Distributed Systems Engineer), inspired by the editorial layout of [tania.dev](https://tania.dev).

Live at: **[sumeshj.in](https://sumeshj.in/)**

---

## Highlights

- **Design System**: Pure white canvas with deep blueberry typography (`#13162b`), underlined links (`#1d4ed8`), and signature berry magenta accents (`#be185d`).
- **Wi-Fi Happiness Widget**: Interactive 2D HTML5 Canvas animation morphing between a network signal and a smiling face (inspired by Ruben Jauregui's motion design shot).
- **Mobile Off-Canvas Drawer**: Smooth overlay navigation and backdrop for screens `<= 842px` without displacing layout content.
- **Modern SEO & Social Meta**: Complete Open Graph, Twitter Cards, JSON-LD (`schema.org/Person`), `sitemap.xml`, and `robots.txt`.
- **Zero Dependencies**: Pure Vanilla HTML5, modern CSS3, and JavaScript — no build steps, bundlers, or heavy UI frameworks.

## Project Structure

```text
sumesh-potfolio/
├── index.html       # Semantic single-page portfolio layout
├── style.css        # Responsive styling & CSS custom properties
├── script.js        # Section scrollspy, mobile drawer, & canvas animation
├── favicon.svg      # Custom geometric "S" monogram SVG favicon
├── og-image.svg     # 1200x630 social preview card for Open Graph / Twitter
├── robots.txt       # Crawler rules & sitemap reference
├── sitemap.xml      # XML sitemap for search indexing
└── Sumesh J - Applied AI & Distributed Systems Engineer Resume.pdf
```

## Quick Start

Run the site locally with any static HTTP server:

```bash
# Using Python
python -m http.server 3000

# Or using Node / npx
npx serve .
```

Open `http://localhost:3000` in your browser.
